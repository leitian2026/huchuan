# 互传 (Hulian)

Android 局域网互传：文字、文件、已安装应用（仅 apk，不含应用数据）。

- 同一 Wi-Fi：mDNS 自动发现，免扫码；找不到时可扫二维码
- 无 Wi-Fi：一方“创建热点”显示二维码，另一方扫码连接；首次配对时谁开二维码，以后谁就建热点，扫码的一方自动去连，不再弹窗选择
- 自动打开开关：Wi-Fi 和系统“定位”关着时，自动连接 / 扫码配对会自动打开（需要 root；定位也可以在电脑上执行一次 `adb shell pm grant com.hulian.transfer android.permission.WRITE_SECURE_SETTINGS` 代替 root）。只还原本 app 自己打开的：离开对话框、退出 app、扫码没配成功时关回去，本来就开着的不动
- 没有 root（或拒绝了授权）：首页“消息”“设备”标题旁显示“没有root”，点一下重新检测；此时开关仍需手动打开
- 图片 / 动图：聊天里直接显示（GIF、动态 WebP 会动，不需要额外的库）；小图（最长边 ≤ 512 像素）按表情包大小显示
- 表情面板：输入框旁的 🙂 按钮。点“+”从相册批量导入，点一下就发，长按删除；长按聊天里收到或发出的图片，选“添加到表情”收藏。表情存在本机（应用私有目录），15MB 以内
- 输入法的表情 / GIF：输入框接收输入法提交的图片（以及长按“粘贴”的图片），收到后立即复制到本机再当普通图片发出。输入法是否会显示图片入口取决于输入法本身：Gboard 支持；国内输入法需要实测
- 接收位置：设置里选一次文件夹，之后记住；未选时存到 下载/互传
- 构建：手动触发。GitHub 仓库 → Actions →「Build Release APK」→ Run workflow，完成后在 Artifacts 里下载 APK（推送代码不会自动构建）
- 发布版（开启 R8 混淆和资源压缩）沿用仓库里固定的签名（app/debug.keystore），每次构建签名一致，可直接覆盖安装，也能覆盖之前装的调试版

协议：TCP，一次连接一条消息 `[4字节头长][JSON头][文件内容]`，对方回 1 字节确认。

## 远程中转（两台手机不在同一个网络时）

- Cloudflare 只做“谁在线 / 有新消息”的小通知；加密后的内容存在坚果云（WebDAV）。内容在手机上加密，Cloudflare 和网盘都看不到。
- Cloudflare 的程序是**单独的仓库**（hulian-relay），不在本项目里，部署方法见它自己的 README。
- 网盘可选：Cloudflare R2（走 S3 接口，不是 WebDAV：地址填 `https://账号ID.r2.cloudflarestorage.com/桶名`，账号填 Access Key ID，密码填 Secret；也可以用 API Token：账号填 Token 的 ID、密码直接填 Token 的值，App 自动取 SHA-256。免费 10GB、出站免费，不显示额度保护；手机时间要准，差 15 分钟以上签名失效）、坚果云（默认）、InfiniCLOUD（免费 20GB、官网称无传输限制，服务器在日本）、自定义（任意支持 WebDAV 的网盘）。每家各记一套地址 / 账号 / 密码，切换不丢；两台手机要选同一家、填同一个账号，“复制配置”会连网盘类型一起带过去
- 手机里：设置 → 远程中转，填 Cloudflare 地址、口令，再选网盘并填账号和“应用密码”。一台填好后点“复制配置”，另一台点“粘贴配置”。
- 加密密钥在两台手机直连配对时交换；更新前配对过的设备，在两台手机同时在线、直连一次时会自动补上。
- 大文件（超过 4MB）自动分段：每段 4MB（超过 256MB 的文件每段 8MB），3 段同时上传（每段一条独立连接，突破单连接的速度上限），每传完一段通知对方，对方同时下载 3 段、边收边写，不用等整个文件传完。文字和不超过一段的小文件仍是一个文件。**两台手机都要更新到这一版**才能收发大文件。
- 传输中的文件可以**暂停 / 继续**（只有远程中转的大文件）和**取消**（直连、远程中转都有，发送方和接收方都能点）。取消会停下传输、删掉写了一半的文件和网盘上的残留，接收方取消时还会通知发送方别再传；暂停时不再开始新的分段，已经在传的传完，暂停期间不算对方超时（最多等 30 分钟）。直连的连接超过 60 秒没数据就会断，所以直连不能暂停；对方取消直连传输时，这边只能看到“连接中断”。暂停不跨重启：App 被杀后变成“已中断”。
- **并行数**在设置 → 远程中转 → 网盘里改（1～8，默认 3），上传和下载共用。坚果云没有公开并发上限，真正的限制是请求次数（免费版每 30 分钟 600 次、付费版 1500 次；超了会被临时封号数小时）和每月流量（免费版上传 1GB、下载 3GB）。
- **额度显示和自动暂停（只对坚果云）**：聊天页顶部常显“上传剩 / 下载剩 / 请求次数”。额度是整个账号共用的，本机数自己的用量，对方的用量由对方在每条通知里带过来（字段 `q`，传完 / 收完后还会补发一条 `qonly`），加起来才是总用量；网页端上传、别的 WebDAV 软件用掉的数不到，在设置里“校准”。请求次数用到上限的 90% 时自动暂停，等最早的请求滑出 30 分钟窗口后自动继续；剩下的月流量不够传下一段时自动暂停，不自动继续（要等下月刷新），点“继续”表示确认、这条传输不再按流量拦。**同步真实用量**：设置里粘贴坚果云网页的登录 Cookie（加密保存在本机，不会被“复制配置”带走），点“同步真实用量”，App 请求一次网页接口 `/d/ajax/userop/getUserInfo`，按坚果云自己记的数据把额度、本周期已用、刷新日改好（返回里的 usedUpRate / freeUpRate / usedDownRate / freeDownRate 是字节数，加起来就是额度；rateResetLeftMills 是距离下次刷新的毫秒数；freeUser 区分免费 / 付费），并提示同步前本机的估算值，方便对照。同步时还会读出本软件所用文件夹（hulian-relay）在坚果云里占的空间（聊天页额度那行末尾显示），以及它的操作历史（`/d/ajax/getEvents`，只含文件的增删改，不含下载和列目录）里最近 30 分钟的条数：它是真实请求次数的下限，本机估算的请求数比它还少时以它为准。没有轮询。Cookie 可以点“登录坚果云”在 App 里的官方登录页登录后自动取回（Android WebView 的 CookieManager 能读到网页脚本读不到的 Cookie；登录成功用页面里同源请求 getUserInfo 能拿到流量数据来判断；取完清掉 WebView 里的登录状态），也可以手动粘贴；过期了重新登录。流量按周期算：设置里填“流量刷新日”（每月几号，坚果云按注册时间算周期，不是自然月，按你自己的刷新日填；两台手机填一样的），到日子自动清零，改刷新日不会清掉已有的用量；也可以点“马上重置本月用量”，本机的用量和校准清零，对方已经报过的用量也不再算，之后新增的照常加上。收完文件后清理网盘残留分段时，请求次数快满也会先等一等。
- **网盘残留会自动清理**：每次连上 Cloudflare 收完未收消息后，顺手清一遍本机在网盘里的文件夹（用同一份文件列表，不多发请求）：已经处理过的消息（收完了、或已经失败结案）还留着的 .bin 和分段、孤儿分段（对应的 .bin 不在了，放够 30 分钟）都会删掉；正在接收的不碰。设置 → 远程中转里也有“清理网盘残留”按钮，马上清一遍（孤儿分段放够 10 分钟就删）。每台手机只清自己的文件夹，发给本机的内容都在里面。
- **限流和一次发多张图片**：不分段的小文件同时最多上传 2 个，服务器回 429 / 5xx 时等几秒重试（最多 2 次）。出错响应里的原因（比如坚果云的 BlockedTemporarily：请求太频繁被临时封了）会读出来显示；碰到它就不再重试、也不再发任何请求，传输自动暂停 30 分钟后试探一次，免得封得更久。
- 每段都是独立的加密文件，带被校验的小消息头（消息编号、发送者、第几段、这段多长），分段不能被调换、截断、少收或混进别的消息。发送中途失败 / 取消，会通知对方并删掉已传上去的分段；对方 2 分钟没有继续上传，接收方放弃并清掉残留。
- 分段通知里多了 `p`（第几段）、`abort`（发送失败）和 `poke`（对方中途上线，叫它去网盘看一下）三个字段。Cloudflare 程序原样转发通知的 body，不用改。
- 对方不在线时不发分段通知：Cloudflare 会把离线设备的通知都存起来（每台最多 200 条），一个大文件的几十条分段通知会挤掉别的消息；对方上线后自己扫描网盘，就能收到已经传好的分段，后面的分段再按通知收。
