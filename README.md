# 互传 (Hulian)

Android 局域网互传：文字、文件、已安装应用（仅 apk，不含应用数据）。

- 同一 Wi-Fi：mDNS 自动发现，免扫码；找不到时可扫二维码
- 无 Wi-Fi：一方“创建热点”显示二维码，另一方扫码连接；首次配对时谁开二维码，以后谁就建热点，扫码的一方自动去连，不再弹窗选择
- 自动打开开关：Wi-Fi 和系统“定位”关着时，自动连接 / 扫码配对会自动打开（需要 root；定位也可以在电脑上执行一次 `adb shell pm grant com.hulian.transfer android.permission.WRITE_SECURE_SETTINGS` 代替 root）。只还原本 app 自己打开的：离开对话框、退出 app、扫码没配成功时关回去，本来就开着的不动
- 没有 root（或拒绝了授权）：首页“消息”“设备”标题旁显示“没有root”，点一下重新检测；此时开关仍需手动打开
- 图片 / 动图：聊天里直接显示（GIF、动态 WebP 会动，不需要额外的库）；小图（最长边 ≤ 512 像素）按表情包大小显示
- 表情面板：输入框旁的 🙂 按钮。点“+”从相册批量导入，点一下就发，长按删除；长按聊天里收到或发出的图片，选“添加到表情”收藏。表情存在本机（应用私有目录），15MB 以内
- 输入法的表情 / GIF：输入框接收输入法提交的图片（以及长按“粘贴”的图片），收到后立即复制到本机再当普通图片发出。输入法是否会显示图片入口取决于输入法本身：Gboard 支持；国内输入法需要实测
- 接收位置：设置里选一次文件夹，之后记住；未选时存到 下载/互传
- 构建：手动触发。GitHub 仓库 → Actions →「Build Release APK」→ Run workflow，完成后在 Artifacts 里下载 APK（推送代码不会自动构建）
- 发布版（开启 R8 混淆和资源压缩）沿用仓库里固定的签名（app/debug.keystore），每次构建签名一致，可直接覆盖安装，也能覆盖之前装的调试版

协议：TCP，一次连接一条消息 `[4字节头长][JSON头][文件内容]`，对方回 1 字节确认。

## 远程中转（两台手机不在同一个网络时）

- Cloudflare 只做“谁在线 / 有新消息”的小通知；加密后的内容存在坚果云（WebDAV）。内容在手机上加密，Cloudflare 和网盘都看不到。
- Cloudflare 的程序是**单独的仓库**（hulian-relay），不在本项目里，部署方法见它自己的 README。
- 网盘可选：坚果云（默认）、InfiniCLOUD（免费 20GB、官网称无传输限制，服务器在日本）、自定义（任意支持 WebDAV 的网盘）。每家各记一套地址 / 账号 / 密码，切换不丢；两台手机要选同一家、填同一个账号，“复制配置”会连网盘类型一起带过去
- 手机里：设置 → 远程中转，填 Cloudflare 地址、口令，再选网盘并填账号和“应用密码”。一台填好后点“复制配置”，另一台点“粘贴配置”。
- 加密密钥在两台手机直连配对时交换；更新前配对过的设备，在两台手机同时在线、直连一次时会自动补上。
- 大文件（超过 4MB）自动分段：每段 4MB（超过 256MB 的文件每段 8MB），3 段同时上传（每段一条独立连接，突破单连接的速度上限），每传完一段通知对方，对方同时下载 3 段、边收边写，不用等整个文件传完。文字和不超过一段的小文件仍是一个文件。**两台手机都要更新到这一版**才能收发大文件。
- 每段都是独立的加密文件，带被校验的小消息头（消息编号、发送者、第几段、这段多长），分段不能被调换、截断、少收或混进别的消息。发送中途失败 / 取消，会通知对方并删掉已传上去的分段；对方 2 分钟没有继续上传，接收方放弃并清掉残留。
- 分段通知里多了 `p`（第几段）和 `abort` 两个字段，Cloudflare 程序需要原样转发通知的 body（目前的 `mid` / `bye` 就是这样转发的）。
